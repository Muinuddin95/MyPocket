# 1. Administrator Manual

### Page 4 (Top): Homepage & Dropdown Menu
**Description**: 
The diagram shows the homepage of the library where the user arrives as a guest. The user can click the profile icon on the top right to open the dropdown menu, which displays Guest, Log In, and Sign Up options. The user can click 'Log In' to access the login page.

---

### Page 4 (Bottom): Login Page
**Description**: 
The diagram shows the login screen where the user can access their account by entering their username and password. Below the login form, there is a link for new users to register an account.

---

### Page 5 (Top): Navigation Bar with Admin Panel
**Description**: 
The diagram shows the homepage after an administrator logs in. The navigation bar displays the 'Admin Panel' option. The admin can click the admin panel option to access the administrative dashboard.

---

### Page 5 (Bottom): Admin Dashboard / Control Panel
**Description**: 
The diagram shows the admin control panel dashboard which displays statistical information about the system. The admin can view metrics such as the number of registered users, books in database, total reviews, total reads, and visitors today. Below this, there is a daily visitors bar chart and a books by genre pie chart.

---

### Page 6 (Top): User Account Control / Registered Users
**Description**: 
The diagram shows the user management section in the admin panel where the admin can view registered users. The table shows the ID, Username, Reviews, Books Read, and action buttons. The admin can delete a user account by clicking the delete button.

---

### Page 6 (Bottom): Manage Books (Reference Example)
**Description**: 
The diagram shows the admin panel where admin can manage books. In the admin panel, the admin can create a new book, by entering the information needed such as book cover picture, book title, author and also the genre. Below it, there is the lists of book where the admin can edit it's information, upload the text file for the book content and also delete the book.

---

### Page 7 (Top): Recent Reviews Section
**Description**: 
The diagram shows the recent reviews section in the admin panel where the admin can monitor student reviews. The table displays the username, book title, and the written review content submitted by students.

---

### Page 7 (Bottom): Fine Portal & Issue New Fine Form
**Description**: 
The diagram shows the administrative fine portal where the admin can manage student fines. The admin can view fine statistics such as total unpaid amount, active fines, pending reviews, and total collected amount. Below it, the admin can issue a new fine by entering username, book title, borrow date, due date, fine type, and amount. A table lists all student fines with filters.

---

### Page 8 (Top): Recent Payments Table
**Description**: 
The diagram shows the recent payments log in the admin panel where the admin can track transaction records. The table lists student names, book titles, paid amount, payment method, payment receipt, and transaction timestamps. The admin can click 'View' to see the receipt or 'Print PDF' to download the summary.

---

### Page 8 (Bottom): Add Borrow Record Form
**Description**: 
The diagram shows the add borrow record form in the admin panel where the admin can check out books to students. The admin can enter details such as username, full name, class, book title, ISBN, borrow date, due date, and notes, then click the add record button.

---

# 2. Client Manual

### Page 9 (Top): Client Login Screen
**Description**: 
The diagram shows the client login screen where a student enters their specific username and password to log into the E-Library system.

---

### Page 9 (Bottom): Client Book Catalogue
**Description**: 
The diagram shows the book catalogue page for clients where students can browse books. The screen includes a search bar to find books, a genre filter dropdown, and a horizontal 'Now Trending' slider displaying trending books with read buttons.

---

### Page 10 (Top): Book Details & Reviews
**Description**: 
The diagram shows the book details page where students can view information about a selected book and read it online. Below the book info, there is a reviews section where students can write and post reviews or read feedback from other users.

---

### Page 10 (Bottom): Client Book Reader
**Description**: 
The diagram shows the book reader interface where students can read the full text content of a book. The reader has a back button to return to the details page and allows students to click any line to bookmark their progress.

---

### Page 11 (Top): Client Fine Portal Dashboard
**Description**: 
The diagram shows the client fine portal where students can track their outstanding fines. The dashboard displays the total outstanding amount, overdue books count, and cleared fines. Below it, a table lists detailed records of past payments.

---

### Page 11 (Bottom): Client Profile & Reading History
**Description**: 
The diagram shows the client profile dashboard displaying student information. The student can view their account status and reading history with timestamps, view logs, and access their posted reviews.

---

### Page 12 (Top): Pay Fine Modal Popup
**Description**: 
The diagram shows the pay fine modal popup where students can pay their outstanding library penalties. The modal displays the payment amount, a dropdown to select the payment method (such as Cash or QR Payment), and buttons to cancel or confirm the payment.
